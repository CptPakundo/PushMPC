Auto: base M1/M2 Light, base M3 and newer Balanced, Pro High, Max/Ultra and M4-or-newer Pro Ultra. Shaders run only when the video is drawn larger than its own size.

Needs PushMPC from Homebrew (brew install pushmpc), which installs the pushmpc-iina bridge: Apple's VideoToolbox interpolation and super resolution (or ArtCNN on Metal) run inside IINA's own player, without changing IINA.app. Off, or when the bridge is not installed: the shader and smooth-motion settings below apply.

Shows every frame for its exact share of display refreshes: no judder on 60, 120 or ProMotion displays. Real frame generation needs the PushMPC filter in mpv (brew install pushmpc).
